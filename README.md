# Nature Gallery - фотогалерея природы

## Назначение
Веб-приложение для хранения и просмотра фотографий природы с описаниями,
категориями и привязкой к месту съёмки. Позволяет пользователю вести личную
коллекцию снимков, добавлять к ним заметки и находить нужные кадры по
категориям или местам.
## Целевая аудитория
Фотографы-любители, путешественники и все, кто хочет сохранять красивые
моменты природы.
## Предметная область
Коллекционирование фотографий природы. Пользователь
загружает снимок, указывает категорию (горы, лес, вода, небо), добавляет
описание и место съёмки, возможно какую-то мысль или то что он чувствует в этот момент. Приложение помогает систематизировать фотографии и находить нужные кадры.

## Основные сущности
- Фотография - название, файл изображения, описание, дата добавления
- Категория - название (горы, лес, вода, небо, другое)
- Место съёмки - название места, координаты (широта и долгота)

## Основные функции
- Добавление фотографии с описанием
- Сортировка фотографий по категориям
- Указание места съёмки
- Просмотр галереи с фильтрацией по категориям

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных для хранения фото;
- реализация пользователей и личных галерей;
- добавление отображения места съёмки на карте;
- разработка API для работы с фотографиями;
- контейнеризация приложения;
- настройка CI/CD.
